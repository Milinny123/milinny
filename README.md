# etf-momentum-screener
小资金支付宝场外基金与场内 ETF 双时段动量筛选和微信推送系统

## 高爆发盘中评分

尾盘分析会调用 `akshare.fund_value_estimation_em(symbol="全部")` 获取东方财富盘中净值估算，并使用：

`爆发得分 = 盘中估算涨幅 × 45% + 近3日 × 30% + 近5日 × 15% + 近20日 × 10%`

估值接口失败或某只基金没有估值时，脚本会使用最新日收益回退并在微信、网页中明确标注，不会把回退值伪装成实时数据。盘中净值估算不是基金公司最终确认净值，也不是可成交价格。

固定核心池覆盖半导体、AI/算力、科创50、动漫游戏、机器人、北证/小微盘、港股科技、有色金属和稀土等高弹性方向；运行时仍会通过基金目录核验代码和名称，错误或失效代码会单独跳过。

## 修改资金规模

在私有仓库进入 `Settings -> Secrets and variables -> Actions -> Variables`，添加或修改：

- `TOTAL_CAPITAL`：总资金，默认 `2000`
- `BUY_MIN`：单笔最小金额，默认 `100`
- `BUY_MAX`：单笔最大金额，默认 `250`
- `BROKER_MIN_COMMISSION`：证券账户每次买入或卖出的最低佣金，默认 `10`
- `INTRADAY_MAX_ROUND_TRIP_COST_PCT`：T+0 日内交易可接受的最高双边固定佣金占比，默认 `1.0`
- `MANAGER_MIN_YEARS`：推荐项偏好的基金经理累计从业年限，默认 `10`
- `ENTRY_MAX_DAILY_MOVE`：单日涨幅超过该值时不追涨，默认 `2.5%`
- `ENTRY_PULLBACK_LIMIT`：单日跌幅超过该值时等待止跌，默认 `2.5%`
- `MIN_BACKTEST_SIGNALS`：入场规则至少需要的历史样本数，默认 `8`

例如计划投入 1000 元，可设置 `TOTAL_CAPITAL=1000`。本地运行时也可以使用：

```bash
TOTAL_CAPITAL=1000 python etf_workbench.py
```

系统会在线核验核心场外基金的代码与名称，报告每个标的的最新数据日期；数据超过 10 个自然日时停止给出交易信号。行情接口、基金净值发布时间和网络状态仍可能导致延迟，输出仅供研究参考。

## 持仓跟踪

私有仓库中的 `holdings.json` 按每笔交易记录基金代码、买入日期、金额、成交净值和确认状态。脚本会把持仓强制加入分析池，在微信报告顶部输出持有、停止加仓、减仓观察等后续操作建议，并按总资金扣除已投入金额，避免继续给出超过剩余现金的买入指令。

支付宝订单未确认时使用 `"status": "pending"` 且 `"cost_nav": null`，脚本不会猜测成交净值或计算虚假盈亏。确认份额后改为 `"status": "confirmed"` 并填写支付宝显示的成交净值。每次加仓必须单独保留一条记录，因为不同批次的赎回费持有期限分别计算。

按当前配置，持仓名称、金额和操作建议会写入公开 GitHub Pages，方便手机查看；成交净值为空时不会猜测收益。不要在 `holdings.json` 中加入身份证号、账户号等敏感信息。

对于小资金，场内 ETF 会先计算买入和卖出两次最低佣金的往返成本，成本超过 1% 时只保留观察信号。支付宝场外 C 类基金没有证券账户最低佣金，但赎回费规则并不统一；系统会实时核验出现买入信号的 C 类基金费率，给出免赎回费所需的计划持有天数，最终以支付宝购买页为准。

系统另设独立的 T+0 日内可执行性检查，仅扫描允许当日回转的代表性债券、黄金和跨境 ETF。普通股票 ETF 仍按 T+1 处理。日内榜会计算 100 份最小交易单位、当前资金最多可买手数和买卖双边最低佣金对应的回本涨幅；达不到成本门槛时明确输出“不交易”。以 1000 元资金、买卖各最低 10 元计算，即使资金全部投入，固定佣金也至少占 2%，且尚未计买卖价差和滑点。

## 网页查询与次日情景

仪表盘采用深色响应式工作台，提供盘中冲刺 Top 3、基金代码/名称查询、板块筛选、板块爆发热度图和 2000 元分批加仓计算器。查询覆盖每次任务实际扫描到的全部标的，展示当前结论、建议金额、计划持有期、基金经理累计从业年限、盘中估值、爆发得分和次日情景区间。未在扫描池中的代码需要先核验后加入，静态 GitHub Pages 不会在浏览器里临时调用行情接口。

推荐项会通过 `fund_manager_em` 核验当前基金经理及累计从业时间；默认偏好至少 10 年。这个年限是经理的累计行业经验，不等于管理当前基金满 10 年，也不能保证更低风险。次日情景区间由短期动量、近 20 日波动和近 3 日相关主题新闻标题共同估算，并显示置信度；它不是确定性预测或收益承诺。

旧版曾要求“最新 1 日涨幅至少 3%”才进入推荐，这会把冲高后的标的当成买点。现在改为：单日上涨超过 `ENTRY_MAX_DAILY_MOVE` 标记为“等待回踩”，单日跌幅超过 `ENTRY_PULLBACK_LIMIT` 标记为“下跌未止”，其余候选还要通过滚动历史回测（同一入场规则的 3/5 日胜率、平均收益和最差结果）。基金经理年限只作为质量提示，不再把指数联接基金一刀切掉。

需要特别区分数据来源：AKShare 是开源数据接口/聚合层，不是交易所或基金公司的“官方保证”。它的开放式基金日净值接口来自东方财富，并且文档注明通常在交易日 16:00–23:00 更新，所以早盘和尾盘不能把 QDII/场外基金的净值当作实时成交价。场内 ETF 会优先使用实时行情和历史行情；赎回费仍以支付宝实际购买页为准。

## 推送可靠性

工作日北京时间 09:00 和 14:20 由独立调度器触发；GitHub Actions 自带 Cron 在 09:05/09:15/09:25 和 14:25/14:35/14:45 提供备用触发。两条路径共用按日期和时段划分的缓存锁，正常情况下每个时段只推送一次。网页手动运行默认也遵守去重锁；只有勾选 `force_push` 才会强制补发。
